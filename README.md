# Raspberry Pi AI HAT+ (26-TOPS)

## 1. Define

The **Raspberry Pi AI HAT+ (26 TOPS)** is an AI accelerator for the **Raspberry Pi 5**, built around the **Hailo-8 NPU**. It provides hardware-accelerated neural-network inference for edge-AI applications.

## 2. Use Case

- Real-time object detection
- Image and video processing
- Camera-based computer vision
- Robotics
- Security and surveillance
- Edge AI inference
- Embedded AI applications
